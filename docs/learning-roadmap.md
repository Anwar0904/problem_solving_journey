# Learning Roadmap

The sequence follows the repository's actual practice history. The first seven entries are present; later topics are ideas, not completed work.

## Completed entries

| Day | Practice | Main idea |
|---|---|---|
| [01](../Day1/README.md) | Find a maximum | Track a best value while scanning a list. |
| [02](../Day2/README.md) | Second largest distinct value | Maintain the two greatest distinct values. |
| [03](../Day3/README.md) | Reverse a string | Use indices to visit characters in reverse order. |
| [04](../Day4/README.md) | Find duplicates | Track values seen and report repeated values once. |
| [05](../Day5/README.md) | Count frequencies | Associate each distinct value with its occurrence count. |
| [06](../Day6/README.md) | Two Sum, nested-loop search | Check pairs of distinct positions until a match is found. |
| [07](../Day7/README.md) | First non-repeating character | Count normalized characters, then scan in input order. |

## Planned next

- **Day 08 — Two Sum with a hash map** (upcoming): revisit Day 6 and explore a different time/space trade-off. No implementation has been added yet.

## Possible later topics

These are suggestions, not scheduled or completed challenges:

- Linear search and binary search.
- Two-pointer techniques on lists and strings.
- Stack and queue operations.
- Sorting and comparing algorithm costs.
- Sets and hash maps for membership and lookup.
- Recursion and introductory tree traversal.

New topics should build on a concrete problem and include an explanation that lets a reader attempt it before viewing an implementation.
