# Learning Resources

These official references can help with the Python features used in the current exercises. The problem guides remain the starting point for each challenge.

- [Python tutorial: data structures](https://docs.python.org/3/tutorial/datastructures.html) — lists, loops, and dictionaries.
- [Python tutorial: strings](https://docs.python.org/3/tutorial/introduction.html#strings) — string operations and indexing.
- [Python library reference: built-in types](https://docs.python.org/3/library/stdtypes.html) — sequence and mapping behavior.
- [Python tutorial: control flow](https://docs.python.org/3/tutorial/controlflow.html) — `for` loops and conditional logic.

The examples in this repository use only Python's standard language features and require no third-party packages.
